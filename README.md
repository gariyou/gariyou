# AI Novel Prompt Builder

ChatGPT・Claude・Claude Code・Codex・Cursor などの AI に小説制作を依頼するための、高品質な「小説構築プロンプト」を生成する Web アプリです。

単なるプロンプト作成ツールではなく、長編小説を破綻なく作るための**設計書生成ツール**として設計されています。各項目の記入欄を埋めていくだけで、AI にそのまま提出できる完成プロンプトがリアルタイムで生成されます。

## 特徴

- **11 セクションの段階的な設計入力** — 作品基本情報 / 作風・トーン / 世界観 / 主人公 / 主要キャラクター / 敵・対立構造 / ストーリー構成 / 章構成 / シーン構成 / 伏線管理 / AI への作業指示
- **複数プロジェクト管理** — 作品ごとに保存スロットを切り替え。作品タイトルから自動命名され、新規作成・削除も可能
- **プロンプトテンプレート切り替え** — フル設計書 / 企画用 / 執筆用 / 校正用の 4 種。冒頭の役割付けと「今回の依頼」ブロックが切り替わり、出力セクションもテンプレートの推奨構成に合わせて自動調整
- **提出先 AI 別のフォーマット** — テキスト（汎用）/ Markdown（ChatGPT・Cursor 向け）/ XML（Claude 向けのタグ構造）の 3 形式で出力・コピー
- **リアルタイムプレビュー** — 入力するそばから右側に完成プロンプトを表示。未入力の項目・セクションは自動的に省略
- **セクション別の出力 ON/OFF** — 「プロットだけ依頼したい」ときなど、プロンプトに含めるセクションをチップで選択(トークン節約にも)
- **複数アイテム管理** — キャラクター・章・シーン・伏線は「追加」ボタンで何件でも登録可能。↑↓ボタンで並べ替えでき、シーンは「所属章」で章に紐付け可能
- **シーンの章別グルーピング** — 所属章を設定したシーンは、プロンプト上で章ごとにまとめて出力。「章構成の順に並べ替え」ボタンで編集画面のシーンも章順に整列
- **伏線の未回収警告** — 伏線に「初出の章」「回収の章」を設定でき、回収の章が未設定・リンク切れ（章の改名/削除）の伏線をセクションとプレビューの両方で警告
- **トークン概算表示** — 文字数に加えて、プロンプトのトークン数の目安を常時表示
- **チップ項目の自由入力** — 想定媒体・重視する要素・AI にやらせたい作業は、定義済みの選択肢に加えて自由入力でチップを追加可能
- **コピー機能** — プレーンテキスト / Markdown 形式の 2 種類でワンクリックコピー
- **JSON エクスポート / インポート** — 設定資料をファイルとして保存・共有・復元（ファイル名は作品名から自動生成）
- **自動保存とバックアップ** — 入力内容はローカルストレージに自動保存。リセット・インポート・作品削除の直前には自動バックアップが取られ、「バックアップを復元」で戻せます
- **誤操作ガード** — 入力済みのキャラ・章・シーン・伏線の削除には確認ダイアログを表示
- **レスポンシブ対応** — スマホでは「入力フォーム / 完成プロンプト」をタブで切り替え
- **ダークモードの高級感ある UI** — 小説制作ツールらしい、夜色と金のテーマ

## 技術スタック

- [React](https://react.dev/)（TypeScript）
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Vite](https://vite.dev/)

外部バックエンドは不要。ブラウザだけで完結するフロントエンドアプリです。データはすべて手元のブラウザ（ローカルストレージ）に保存され、外部には送信されません。

## セットアップ手順

Node.js 18 以上が必要です。

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動（http://localhost:5173）
npm run dev

# 本番ビルド（dist/index.html に単一ファイルで出力）
npm run build

# ビルド結果のプレビュー
npm run preview
```

ビルドは JS/CSS をすべて埋め込んだ**単一の `dist/index.html`** を出力します。このファイルは**ダブルクリックするだけでブラウザで起動**でき、サーバーもインターネット接続も不要です。デスクトップに置いたり、他のPCにコピーして使えます（GitHub Pages / Netlify などへの配置も従来どおり可能です）。

なお、入力データは「開いたブラウザ」の localStorage に保存されます。別のブラウザやPCに移るときは「JSON でエクスポート」→「JSON をインポート」でデータを引き継いでください。

## 使い方

1. **左側のフォームを埋める** — 各セクションは折りたたみ式です。見出しをクリックして開き、書ける項目から埋めてください。全項目を埋める必要はありません（空欄はプロンプトから省略されます）
2. **プレースホルダーを参考にする** — 各入力欄には記入例が薄く表示されています
3. **キャラクター・章・シーン・伏線を追加する** — 各セクションの「＋ 追加」ボタンで何件でも登録できます。↑↓で並べ替え、シーンは「所属章」で章に紐付けられます
4. **右側のプレビューを確認する** — 入力内容が即座に完成プロンプトへ反映されます。「テンプレート」で依頼の種類（フル設計書 / 企画用 / 執筆用 / 校正用）を選び、「出力するセクション」のチップでプロンプトに含めるセクションを絞り込めます
5. **提出先に合わせた形式でコピーする** — 出力形式（テキスト / Markdown / XML）を選んで「コピー」を押してください。ChatGPT・Cursor には Markdown、Claude には XML がおすすめです
6. **作品を切り替える** — ヘッダーのセレクトで作品を切り替え、「＋ 新規作品」で 2 作目以降を並行執筆できます
7. **設定資料を保存する** — 「JSON でエクスポート」でファイル保存、「JSON をインポート」で復元できます
8. **やり直す** — 「リセット」で現在の作品の入力を消去します。直前の内容は自動バックアップされ、「バックアップを復元」で戻せます

### おすすめの運用フロー

1. まず「作品基本情報」「作風・トーン」「AI への作業指示」だけ埋めて、AI に**企画・プロット作成**を依頼する
2. AI の提案を元に「世界観」「主人公」「キャラクター」「対立構造」を確定させる
3. 「章構成」「シーン構成」「伏線管理」まで埋めたら、**本文執筆**を依頼する
4. 執筆が進んだら「矛盾チェック」「キャラ口調チェック」「伏線チェック」を依頼する

## 対話で作る（Claude Skill）

フォームを埋める代わりに、Claude と会話しながら設計書を作れるスキル `novel-prompt` を同梱しています（`.claude/skills/novel-prompt/`）。

- **軽量モード** — 質問4つ（ジャンル・コンセプト・主人公・分量）に答えるだけで、残りは Claude が提案して11セクションを埋める
- **フルモード** — 11セクションを順に、対話で決めていく
- 最後に**完成プロンプト**と、本アプリの「JSONをインポート」で取り込める**互換JSON**を出力。「チャットで雑に作る → アプリでじっくり調整」の往復ができます

使い方:

- **Claude Code** — このリポジトリでセッションを開き `/novel-prompt` と入力（または「小説のプロンプトを作りたい」と話しかける）
- **claude.ai / Cowork** — `.claude/skills/novel-prompt/` フォルダを zip にして、claude.ai の 設定 → 機能（Capabilities）→ スキル からアップロード

## 改良案

今後の拡張アイデア:

- **ドラッグ & ドロップ並べ替え** — 現在の↑↓ボタンに加えて、掴んで動かせる並べ替え
- **正確なトークンカウント** — 現在の文字数ベースの概算を、モデル別トークナイザによる実測値に置き換える
- **Markdown ファイルとしてのエクスポート** — 設計書を `.md` ファイルとしてダウンロード
- **入力サジェスト** — ジャンル定番の対立構造・章構成のプリセット挿入
- **テンプレートの自作** — 依頼文と推奨セクション構成をユーザーが定義できるカスタムテンプレート
- **多言語対応** — 英語 UI / 英語プロンプト出力
