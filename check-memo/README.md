# チェックメモ

Android のブラウザで使える、Google ドライブ保存のチェックリスト型メモアプリです。
Google Apps Script で動くので、サーバーの用意やアプリのインストールは不要です。

## できること

- やることを追加(Enter で追加、Shift+Enter で改行)
- チェックすると **「完了」ページに日付・時刻付きで移動**(日付ごとにまとめて表示)
- 完了ページの「戻す」でやることリストに戻せる。チェック直後は「元に戻す」も可能
- タップで編集・削除・並べ替え(↑↓)
- 「買い物」「仕事」など複数のリストを作れる
- データは自分の Google ドライブの `チェックメモ/checkmemo-data.json` に保存
- 電波がないときも操作でき、つながったら自動でドライブに保存
- 複数の端末(スマホと PC など)から使っても、操作単位で反映されるので上書きで消えない

## セットアップ(5 分くらい)

PC でやるのが楽ですが、Android の Chrome でも「PC 版サイト」にすれば可能です。

1. <https://script.google.com/> を開き、「新しいプロジェクト」を作る
2. プロジェクト名を「チェックメモ」に変える
3. `コード.gs` の中身を全部消して、このフォルダの [`Code.gs`](Code.gs) の内容を貼り付ける
4. 左の「ファイル」の「＋」→「HTML」で `index` という名前のファイルを作り、[`index.html`](index.html) の内容を貼り付ける
5. (任意)左の「プロジェクトの設定」→「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェックし、[`appsscript.json`](appsscript.json) の内容を貼り付ける
6. 右上の「デプロイ」→「新しいデプロイ」
   - 種類の選択: 「ウェブアプリ」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **自分のみ**
7. 「デプロイ」を押すと Google ドライブへのアクセス許可を求められるので許可する
   (「このアプリは Google で確認されていません」と出たら「詳細」→「チェックメモ(安全ではないページ)に移動」。自分で作ったスクリプトなので問題ありません)
8. 表示された「ウェブアプリの URL」(`https://script.google.com/macros/s/…/exec`)をコピー

## Android のホーム画面に置く

1. Android の Chrome で上の URL を開く(同じ Google アカウントでログインしておく)
2. 右上の「⋮」→「ホーム画面に追加」
3. ホーム画面のアイコンから、アプリのように起動できます

## コードを更新したとき

「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」→「デプロイ」。
こうすると URL が変わらないので、ホーム画面のアイコンはそのまま使えます。

## データについて

- 保存先: Google ドライブの `チェックメモ` フォルダ内 `checkmemo-data.json`(メニューの「ドライブの保存ファイルを開く」から開けます)
- ファイルは JSON なので、バックアップはこのファイルをコピーするだけです
- ファイルを削除すると、次回起動時に空の状態で作り直されます
