# 灰燼の迷宮（Ashen Crawl デモ）

ブラウザだけで動く、見下ろし型アクション RPG の小さな見本です。
「Tripo で 3D モデルを作り、Web ゲームに入れて、URL で配る」流れを試すために作りました。

- three.js（CDN 読み込み）を使った 1 ファイル構成。ビルドは不要です
- 部屋の敵を全滅させると中央にポータルが開き、次の深度へ進みます。3 層ごとにボス「骨の巨像」が出ます
- 斬撃・範囲攻撃（灰燼ノヴァ）・ダメージ数字・ヒットストップ・画面揺れ・粒子エフェクト・ボスの範囲攻撃予告つき
- PC（キーボードとマウス）とスマホ（仮想スティックとボタン）の両方で遊べます

## 遊び方

`index.html` をブラウザで開くだけで動きます（three.js を CDN から読むので、ネット接続は必要です）。

| 操作 | PC | スマホ |
| --- | --- | --- |
| 移動 | WASD・矢印キー | 画面左側をドラッグ |
| 斬撃 | 左クリック（マウスの方向へ） | 「斬」ボタン（近くの敵へ自動で向く） |
| 灰燼ノヴァ | Space・右クリック | 「爆」ボタン |

## Tripo のモデルを入れる

今は仮の見た目（箱や球の組み合わせ）です。Tripo などで作った `.glb` に差し替えられます。

1. Tripo（Web 版・API・CLI のどれでも）でモデルを作り、GLB 形式で書き出す
   - リグとアニメーション付きで書き出すと、`idle` と `walk` / `run` という名前のクリップを自動で使います
2. 次のどちらかで読み込む
   - **画面から**: 右上の「モデル差し替え」で GLB を選ぶ（主人公用と敵用の 2 つ）
   - **ファイルを置く**: `game-demo/models/player.glb` と `game-demo/models/enemy.glb` に置き、
     `npx serve game-demo` などのローカルサーバーで開く（`localhost` で開いたときだけ自動で読みます）
3. 向きが逆なら「向きを反転」を押す

大きさは自動で合わせます（主人公 1.8、敵は種類ごとの高さ）。

## Web に公開する

静的ファイルだけなので、GitHub Pages・Netlify・Cloudflare Pages などにそのまま置けます。
`models/` に GLB を置いて公開した場合は、URL の末尾に `?models` を付けると自動で読みます。
